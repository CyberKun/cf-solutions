# Competitive programming solutions

C++ solutions and practice material from my competitive programming work.

[Codeforces: Bruten](https://codeforces.com/profile/Bruten) · [GitHub profile](https://github.com/CyberKun)

## Repository layout

- Numbered directories such as `800/`, `1400/`, and `2200/` group problems by difficulty rating.
- `CSES/` contains CSES practice solutions.
- `Sphere Online Judge/` contains SPOJ material.
- `Contests/` contains contest practice.
- `Problem Setting/` contains problem-setting material.

Each solution is an independent program. This is a practice archive, not a single application or a guarantee that every solution is accepted.

## Compile and run

Use a C++ compiler such as GCC with C++20 support. Replace the example path with the solution you want to run:

```sh
g++ -std=c++20 -O2 -Wall -Wextra "path/to/solution.cpp" -o solution
./solution < input.txt
```

On Windows, the executable may be named `solution.exe`; run it from your terminal using the input format in the original problem statement. Some solutions may use GNU-specific headers or extensions.

## Reading the solutions

Use the original platform's problem statement for constraints and input/output examples. Try solving the problem before consulting a solution, and verify edge cases when adapting an approach.
